# Librerias

## Backend
- `laravel/framework`: base del proyecto.
- `laravel/breeze`: autenticacion web sencilla y mantenible con Blade.
- `spatie/laravel-activitylog`: auditoria de acciones sensibles.
- `barryvdh/laravel-dompdf`: exportacion PDF del carnet de salud del vehiculo.

## Frontend
- `tailwindcss`: implementacion visual rapida con tokens propios.
- `alpinejs`: interactividad ligera para modales, cotizacion y agenda.
- `vite`: pipeline de assets.

## Calidad
- `phpunit/phpunit`: pruebas unitarias y feature.
- `laravel/pint`: formateo consistente.
- `playwright`: validacion automatizada de breakpoints y deteccion de overflow horizontal en navegador real headless.

## Justificacion global
- Todas las librerias elegidas reducen complejidad accidental y mantienen la app cercana a convenciones Laravel, evitando una SPA innecesaria.
